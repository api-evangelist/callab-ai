# Callab AI

> Callab AI, built by Clusterlabs, is a cloud-based voice AI platform that connects directly to legacy on-premises PBX/SBC telephony (Cisco UCM, Mitel, FreeSWITCH) via SIP trunk integration, routing calls to AI voice agents with no rip-and-replace migration. It automates up to 70% of inbound and outbound call volume across support, sales, and scheduling. A Y Combinator Spring 2026 company founded in 2024.

This llms.txt was generated by the API Evangelist enrichment pipeline from the Callab AI public surface and the catalog record; it is not published by Callab AI. The public API reference is gated behind an access code and no public OpenAPI specification was available at generation time.
